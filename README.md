# InstaBuilt — Public Website (Phase 1)

Production-ready public site for **InstaBuilt**, a modular / offsite construction
company. Static HTML5 + CSS3 + vanilla JS (ES6+). No framework, no build step,
no backend — deploy as-is to Vercel.

## Stack

- Plain semantic HTML5
- CSS3 (custom properties, grid, flexbox) — `css/main.css`
- Vanilla JavaScript (ES6+) — `js/main.js`
- Google Fonts: **Fraunces** (display) + **Manrope** (text)

## Run locally

```bash
python -m http.server 8123
# open http://localhost:8123
```

## Placeholder images

Every image is a clearly-labelled architectural placeholder (SVG) generated by
`scripts/generate-placeholders.py`. To swap in real photography/renders, drop a
file with the **same name** into the same folder and update the `<img src>` (or
overwrite the `.svg` in place). See `images/README.md`.

## Link audit (zero 404s)

`scripts/audit-links.py` checks every internal `href` / `src` / `action` against
the filesystem and fails on any broken reference:

```bash
python scripts/audit-links.py
# Checked 794 internal references across 17 pages. OK.
```
