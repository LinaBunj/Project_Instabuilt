# InstaBuilt — Image assets

This folder holds the site's imagery. In the current Phase 1 build every image is
a **labelled architectural placeholder** (SVG), generated by
`scripts/generate-placeholders.py`. Each placeholder shows a muted earth-tone
wash, a modular line-art motif, and a caption describing the intended content.

## Folder convention

Each page has its own clearly-named folder:

```
images/
├── home/                  → Home page
├── popup-solutions/       → POP UP Solutions
├── multistory-multifamily/→ Multistory Multifamily
├── senior-housing/        → Senior Housing
├── micro-apartments/      → Micro Apartments
├── traditional-homes/     → Traditional Homes
├── signature-homes/       → Signature Homes
├── bathpods/              → Bathpods
├── construction-system/   → Construction System
├── sustainability/        → Sustainability
├── about-us/              → About Us
├── career/                → Career
├── innovation-center/     → Innovation Center
├── blog/                  → Blog thumbnails
├── news/                  → News thumbnails
└── contact/               → Contact
```

## Swapping in real imagery (Phase 2)

1. Export your photography or renders with the **exact same filename** as the
   placeholder (e.g. `popup-solutions/hero.svg` → `popup-solutions/hero.jpg`).
2. Update the matching `<img src="…">` in the page markup to the new extension
   (or overwrite the `.svg` file in place — the `src` will keep working).
3. Re-run `python scripts/generate-placeholders.py` at any time to regenerate
   the placeholder set.

No build step is required — files are served as-is by Vercel.
